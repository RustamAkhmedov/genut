**Code (Programmieren)**
- Code-Beispiele als `code`-Block mit `sprache` (z. B. `java`, `javascript`, `typescript`, `html`, `css`, `python`). Code vom Foto exakt übernehmen.
- Bei wichtigen Beispielen `erklaerungen` Zeile für Zeile (`zeilen` z. B. `"3"` oder `"5-7"`, gezählt ab 1) – knapp, für Schüler verständlich.
- Ergänze zu jedem Konzept ein kurzes, vollständiges, lauffähiges Beispiel (`quelle: "ki"`).
- Typische Fehler (z. B. `==` vs. `equals` in Java, `this` in JavaScript, Einrückung in Python) als `hinweis` mit `art: "falle"`.
- Klassen-, Sequenz- oder Ablaufdiagramme als `diagramm`-Block (Mermaid `classDiagram`, `sequenceDiagram`, `flowchart TD`).
- Aufgaben: Lösungsweg in Schritten mit Code-Blöcken; `ergebnis.md` enthält die fertige Lösung. Kein `check` – Code wird nicht ausgeführt.
- **Code-Quiz:** Mindestens die Hälfte der Quizfragen bezieht sich auf konkreten Code: „Was gibt dieses Programm aus?“, „Wo ist der Fehler?“, „Welche Zeile …?“. Den Code in `frage_md` als Markdown-Codeblock mit Sprache. Rechne die Ausgabe sorgfältig im Kopf nach.
